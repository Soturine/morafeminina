# Moda Local Chic

Crie um site completo, moderno, profissional e responsivo para uma loja física chamada Moda Moda Feminina, localizada em Jacareí - SP.

Quero um resultado que pareça ter sido desenvolvido por uma agência profissional de moda, e não um template genérico ou um site com aparência de projeto gerado por IA.

1. Objetivo do site

O site deve funcionar principalmente como:

vitrine digital da loja;

apresentação da marca;

catálogo de produtos e categorias;

geração de contatos pelo WhatsApp;

divulgação da localização física;

divulgação de retirada e entrega;

fortalecimento da presença da empresa no Google;

prova social por meio das avaliações dos clientes;

canal para futuras campanhas, coleções e promoções.

Não implementar checkout ou pagamento online nesta primeira versão.

Os produtos devem direcionar o cliente para o WhatsApp, permitindo perguntar sobre preço, tamanho, disponibilidade, cores e entrega.

O site deve ser estruturado de forma que um e-commerce possa ser adicionado no futuro sem precisar reconstruir toda a aplicação.

21. Performance

O site deve ser rápido especialmente no celular.

Aplicar:

lazy loading de imagens;

imagens responsivas;

dimensionamento correto;

evitar bibliotecas desnecessariamente grandes;

evitar JavaScript excessivo;

evitar animações pesadas;

evitar vídeos automáticos;

prevenir layout shift;

carregar fontes de maneira eficiente.

Buscar boas métricas de Core Web Vitals.

22. Acessibilidade

Seguir boas práticas WCAG.

Garantir:

contraste adequado;

navegação por teclado;

foco visível;

HTML semântico;

labels;

atributos ARIA apenas quando necessários;

alt text nas imagens;

botões com nomes claros;

tamanho confortável de elementos tocáveis no mobile;

suporte a prefers-reduced-motion.

Não substituir elementos HTML nativos por componentes JavaScript sem necessidade.

23. Responsividade

Projetar mobile-first.

O site precisa funcionar muito bem em:

smartphones pequenos;

smartphones grandes;

tablets;

notebooks;

desktops;

telas grandes.

O mobile é prioridade porque grande parte dos clientes provavelmente chegará por Google Maps, redes sociais ou WhatsApp.

24. UX

A navegação deve ser simples.

Onde ela fica?

Ela é confiável?

Posso retirar ou receber minha compra?

Evitar pop-ups invasivos.

Não pedir cadastro.

Não exigir login.

Não criar etapas desnecessárias antes de entrar em contato.

25. Arquitetura do projeto

Desenvolva com código organizado e preparado para manutenção.

Preferências:

React;

TypeScript;

componentes reutilizáveis;

tipagem adequada;

Evite overengineering.

Essa é uma loja local e o projeto deve permanecer simples, rápido e fácil de manter.

Não adicionar backend ou banco de dados apenas porque é possível.

Se o catálogo inicial puder ser mantido de forma simples e tipada, prefira a solução mais simples.

Deixar uma fronteira clara para futuramente migrar os produtos para Supabase ou outro backend sem reconstruir a interface.

links externos devem seguir práticas seguras;

não coletar dados pessoais sem necessidade.

Se futuramente houver formulário, analytics ou cookies não essenciais, adequar o projeto à LGPD.

Nesta versão, minimizar coleta de dados.
